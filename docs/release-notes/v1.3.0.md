**Download `wiikart.zip`**, unzip it, and open `wiikart.dol` in
[Dolphin](https://dolphin-emu.org) — or copy the `apps` folder to an SD
card and launch it from the Homebrew Channel on a real Wii.

Version 1.3.0 is the tuning-and-feedback release. The roads give a full
twelve-car field a little more room, the most aggressive AI drivers are
allowed to overcommit and fall off unguarded passes, Monarch is now a
longer and nastier circuit, and a cliff fall has a readable recovery
sequence instead of an instant reset.

The repository includes the [full v1.3.0 changelog](https://github.com/Nessie404/starwarsgame/blob/v1.3.0/CHANGELOG.md)
and a [future-work list](https://github.com/Nessie404/starwarsgame/blob/v1.3.0/TODO.md).
The TODO is roadmap material only; none of it is being quietly advertised as
finished in this release.

### Edit the game without editing C

The release includes three documented JSON files in
`apps/wiikart/config/`:

- `cars.json` defines every selectable car in real units. Edit a car or
  append a new object to add it to the garage; no source changes are
  required.
- `settings.json` contains the useful race, physics, AI, track-width,
  power-up, and recovery tuning controls.
- `controls.json` contains the keyboard bindings, logical GameCube inputs,
  recommended physical Xbox controls, and the input-display switch.

Bad or missing files do not strand the game. Each file is validated
independently, invalid values are rejected with a short menu warning, and
the matching built-in defaults remain active.

### An input translator, because Dolphin has opinions

The optional live input panel shows the whole path from the control in
your hand to the action in the game: keyboard key and raw state,
recommended Xbox control, logical GameCube input and raw state, and the
final steering, gas, brake, handbrake, item, and shift state. It also
reports which keyboard, GameCube, and Wii device classes are present.
This makes a bad Dolphin mapping visible instead of leaving you to infer
it from a car reversing into a mountain.

The in-race menu action now pauses behind a leave-race confirmation. A
mapped confirm deliberately abandons the event; Back or Menu again returns
to the same frozen moment, so one stray Start press cannot erase a likely
win.

Mario Kart Wii has no manual transmission binding of its own. For
WiiKart's optional manual gearbox, a sideways Wii Remote now uses D-pad
Up/Down and a Classic Controller uses ZR/ZL. GameCube, Xbox, and keyboard
bindings are listed in `controls.json` and the README.

### Wider roads, fallible rivals, harder Monarch

Every circuit is modestly wider. The extra room helps the twelve-car grid
without turning the mountain passes into airport runways. Aggressive AI
strategies now have a small, deterministic chance to keep a late-braking
move alive past the sensible point on an unguarded corner. They can save
it, learn from it, or go over the edge; cautious drivers remain cautious.

Monarch has an extended summit and descent, more tightly linked
switchbacks, a larger climb, and a longer lap. Its pavement is wider than
before, but the additional speed, elevation change, and unguarded corner
sequence make it the harder circuit overall.

### Cliff recovery you can actually read

After a visible fall, that player's viewport holds on black for one
second and then fades back to the checkpoint. The recovered car flashes
and ignores contact from other cars for about five seconds, so the field
cannot immediately punt it back into the same ravine. Progress is still
rolled back by the signed distance actually lost, preserving the v1.2.1
fix that prevents a near-finish fall from awarding most of a free lap.

### Source review cleanups

- Runtime car indexes are checked against the loaded roster rather than a
  compile-time count.
- Falling and recovering cars no longer participate in kart-to-kart
  collision resolution.
- Release packaging now includes the editable configuration files and a
  control chart that agrees with the game.
- Stale version-history ordering and Homebrew Channel description text
  have been corrected.
