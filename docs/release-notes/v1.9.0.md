**Download `wiikart.zip`**, unzip it, and open `wiikart.dol` in
[Dolphin](https://dolphin-emu.org) — or copy the `apps` folder to an SD
card and launch it from the Homebrew Channel on a real Wii.

### You can see the finish line now

On the **minimap**, a black-and-white gate is drawn across the road where
the lap ends, with a flag beside it — so the map says which bend is the
last one instead of leaving you to count.

In the **race view**, a checkered flag and the distance to the line fade
in over the last 220 m of a lap. On the final lap it appears from 400 m
out and says **FINAL LAP** underneath.

### About the JSON — it works, but Dolphin needs an SD card

The parsing was never the problem, and there is now a test that proves it
end to end: it reads the shipped `config/cars.json`, changes SPORT from
150 hp to 210, loads the edited file the way the game does, and checks the
garage reports 210.

What almost certainly happened is this: **opening `wiikart.dol` directly
in Dolphin gives the game no filesystem at all.** With no SD card
inserted, there is nothing to read, so the JSON beside the executable was
ignored and the built-in defaults were used — and the only thing on screen
saying so was a small `BUILT IN CONFIG` label.

Three things change:

- **A JSON CONFIG screen** on the main menu. It shows where the files were
  read from, whether each of the three loaded or the parse error that
  stopped it, and the roster that resulted — `4 CARS  RACER 48 HP`. Edit
  that car's `power_hp`, restart, and if the number changes, your file is
  being used. If it says `NO SD CARD FOUND`, it never saw a file.
- **A wider search.** Each file is looked for on its own across several
  locations, in both the layout the release ships (a `config` folder
  beside `boot.dol`) and the flat one people improvise (the file dropped
  straight in).
- **The instructions say it plainly.** In Dolphin: Config → Wii → Insert
  SD Card, put the release's `apps` folder on that card, launch
  `boot.dol` from there. On a real Wii through the Homebrew Channel there
  is nothing to set up.
