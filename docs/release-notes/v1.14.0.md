# WiiKart 1.14.0

A rechargeable turbo, for cars built to have one.

## The boost button

Some cars now have a turbo. Hold the button and the engine gets a real
power multiplier for as long as the charge lasts; let go, or lift off the
throttle, and the charge climbs back — but only while off the throttle,
never while holding it. That trade is the whole point: recharging costs
the speed accelerating would have bought, so spending the boost well
means deciding when a straight is worth more to you full-throttle than it
is banking charge for later.

It only does anything for a car that actually has one. `cars.json` gained
a fifth car, `TURBO`, as a worked example, and adding the same `"turbo"`
block to any other car in your own file gives it the button too:

```json
"turbo": {
  "power_multiplier": 1.40,
  "boost_seconds": 2.5,
  "recharge_seconds": 5.0
}
```

A gauge sits next to the tire bar for a car that has one, and turns amber
while it's actually being drawn on.

Reach it with **B** (player 1) or **N** (player 2) on a keyboard, **D-pad
up** on a Classic Controller, or the GameCube/Xbox binding
(`DPAD_UP` by default — editable in `controls.json` like every other
control). There is no dedicated button for it on a bare Wii Remote or Wii
Remote + Nunchuk; both are already out of buttons to spare.

The AI decide for themselves when to spend theirs: on a straight, with
real charge in hand, and only while they would be accelerating anyway —
firing it while already sitting at the speed the next corner's braking
point allows would just waste the charge for nothing. It measurably
works: given identical skill and identical learned corner confidence, a
turbo-equipped car laps Berthoud in 72.6 seconds against 74.3 for the
same car without one.

## Playing it

Download `wiikart.zip`, unzip, and open `wiikart.dol` in
[Dolphin](https://dolphin-emu.org) (File > Open). On a real Wii, copy the
`apps` folder to an SD card and launch it from the Homebrew Channel.

To edit `cars.json`, `settings.json` or `controls.json` in Dolphin you need
an SD card: Config > Wii > Insert SD Card, put the `apps` folder on it, and
launch `boot.dol` from there. The JSON CONFIG screen on the main menu tells
you what was actually read.
