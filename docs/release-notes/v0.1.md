The original arcade kart racer, before the 1.0 driving model.

**Two downloads here:**

- **`wiikart-0.1.1.zip` — v0.1.1, the one you want.** The same game plus
  procedural sound, WASD on the keyboard, and the steering-polarity fix
  (left really is left). Built from `v0.1` plus `patches/v0.1.1.patch`.
- `wiikart.zip` — v0.1 exactly as first published, steering inversion and
  all, kept for the record.

Unzip and open `wiikart.dol` in the [Dolphin](https://dolphin-emu.org)
emulator, or copy the `apps` folder to an SD card and launch it from the
Homebrew Channel on a real Wii.

v0.1.1 has no tag or release of its own because this repository refuses to
create one — `patches/README.md` has the details.
