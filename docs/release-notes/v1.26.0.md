# WiiKart 1.26.0

Weather on every circuit instead of just one, behind a toggle you
control from the race setup menu, and an AI field where skill now
visibly shows up as line quality — not just how much grip a driver
dares to use.

## Weather everywhere, with a toggle

CLASSIC has had weather since v1.19.0: patches of road that start as
snow, melt into ice, and settle into a puddle, each stage handing an
advantage to a different tire compound. Every other circuit's weather
zones stayed empty forever — not a design choice so much as something
nobody had gotten back to.

`track_init` now builds the same three-zone snow-to-ice-to-puddle
layout for all nine circuits, derived from nothing but each track's own
length, so a longer or shorter lap just spreads the same three patches
over more or less road. Whether any of it actually shows up in a race
is a separate question: a new WEATHER row in the setup menu, next to
LAPS, turns it on or off for the whole field, off by default. Turn it
on and every circuit's road tint and the HUD's "weather ahead" readout
work exactly as they always did on CLASSIC — they were already reading
`track_weather_at` generically, so there was nothing else to wire up.

## Skill that shows up on track

WiiKart's AI has read the real racing line since v1.13.0 — the track's
own signed curvature, not a fixed lateral offset — and some drivers
have anticipated further up the road than others since v1.21.0. What
skill never touched was how well any of that got executed: a 0.87-skill
driver and a 1.05-skill driver on the same strategy sheet drove
identically precise lines, differing only in how much grip they dared
to carry into the corner.

Two places now read skill directly as execution quality. The rate a
driver's `line_target` eases onto the ideal apex line `ai_tactical_line`
finds each frame now scales with skill — a lower-skill driver still
eases toward the same point a sharper one does, just more slowly, so it
is measurably still settling into a corner a high-skill driver already
committed to. And the tactical moves layered on top of that base line —
covering the side a human keeps passing on, lining up on the opposite
side of a car it's hunting — are scaled by the same skill read: the
strategy sheet still decides who *wants* to defend or attack, skill
decides how fully they actually pull it off. A low-skill DEFENDER still
tries to cover the door; a high-skill one shuts it properly.

None of this changes where the racing line itself comes from — every
driver already reads the track's own geometry rather than something
hardcoded. This is skill determining how well that read gets carried
out, not a new line source.
