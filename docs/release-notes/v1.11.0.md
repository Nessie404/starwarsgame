# WiiKart 1.11.0

Two things: a build defect that could make any release refuse to open, and
an AI that drives your car home after the flag.

## The DOL was short, and a loader noticed

`elf2dol` ends the file at the last section's real size. A loader reads
sections in 32-byte units, so when that size is not a multiple of 32 the
file promises up to 31 bytes it does not contain. Dolphin's
`DolReader::Initialize` rejects the entire executable for that, and all you
see is **"Failed to init core"** — reported before the console executes one
instruction, which is why nothing the game logs can tell you about it.

Whether a given build has the defect is luck: it depends on the last
section's size modulo 32, so it appears and disappears as unrelated code is
added. WiiKart shipped it in v0.1 (12 bytes short) and in v1.0, v1.0.1,
v1.1.0 and v1.2.1 (28 bytes short each).

From this release `tools/pad_dol.py` runs from the Makefile after every
build and appends exactly the missing zero bytes, and
`tools/validate_dol.py` fails the build if a section still reaches past the
end of the file. It was the validator that caught this, by refusing to
publish a build that was 4 bytes short.

## An AI drives your car home

Crossing the line used to hand your car to a driver with no plan. On a
mountain pass that could mean driving straight off it, which is a poor
reward for winning.

Now a cool-down driver takes over. It picks an aim point on the shoulder on
whichever side of the road you are already on, scans 55 m ahead and slows
for whatever corner is coming, and bleeds its target speed down to nothing
over eleven seconds before parking the car. It touches the brakes only when
it is genuinely going faster than it wants to, so the car rolls to a stop
instead of standing on the pedal.

Everyone who finishes gets it, not only the player, so the field comes home
together rather than scattering down the mountainside.

Measured on Monarch, Guanella and Berthoud: no falls, no reversing, at
least 30 m of driving after the flag, and a real standstill at the end.

## Also

- The DOL validator no longer flags the loader's 32-byte rounding reaching
  a few bytes into the start of BSS. Every normal DOL does that and crt0
  zeroes BSS before `main`, so it is a note now; only a section whose
  advertised extent runs into BSS is a collision.
- The historical patch workflow pads the DOL as well, so a fix built on an
  old tag produces a loadable binary even though that tag's Makefile
  predates the padding step.

## Playing it

Download `wiikart.zip`, unzip, and open `wiikart.dol` in
[Dolphin](https://dolphin-emu.org) (File > Open). On a real Wii, copy the
`apps` folder to an SD card and launch it from the Homebrew Channel.

To edit `cars.json`, `settings.json` or `controls.json` in Dolphin you need
an SD card: Config > Wii > Insert SD Card, put the `apps` folder on it, and
launch `boot.dol` from there. The JSON CONFIG screen on the main menu tells
you what was actually read.
